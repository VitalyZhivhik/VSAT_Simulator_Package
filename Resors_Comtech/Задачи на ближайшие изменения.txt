В разделе Profoles при попытке выбора профиля в разделе Mode появлется окно Basic оно общее для всех профилей, также в нём по умолчанию выбран профиль none. После выбора определённого профиля между заголвком с номером профиля и таблицей Basic settings радом с настройкой Basic появляются настройки индифидуальный для каждого профиля они также лежат в папках \Параметры <названиее профиля>, при нажатии на эти параметры возникают странички этих параметров где идёт их настройки. Необходимо реализовать такую же системы в программе, на данный момент достатончо просто запоминать в программе сохранённые пользователем пареметры.
Также в разделе Network в вкладке Station необходимо реализовать возможность добавления станции, это делается следующим образом: В таблице Table parameters создаётся таблица опрделённого размера, далее пользователь пишет номер станции в таблице Station edit в разделе Number может поставить галочку On тогда станция считается включённой, после чего при нажатии на кнопочку Apply станция добавляется в таблицу справа.
